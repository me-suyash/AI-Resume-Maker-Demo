# AI Resume Maker — UI Demo

This is a small, beginner-friendly Flask demo for presenting the planned screens of the AI-Powered Resume Maker.

## Run
1. Install Python 3.10+.
2. Open a terminal in this folder.
3. Run: `python -m venv venv`
4. Activate it:
   - Windows: `venv\\Scripts\\activate`
   - macOS/Linux: `source venv/bin/activate`
5. Run: `pip install -r requirements.txt`
6. Run: `python app.py`
7. Open: http://127.0.0.1:5000

## Important
This is a **UI demonstration only**. Upload, OCR, AI writing, database saving and PDF export are not implemented. Buttons show demo messages or navigate between sample pages. The sample resume information is fictional placeholder content; replace it with approved test data before any presentation.
